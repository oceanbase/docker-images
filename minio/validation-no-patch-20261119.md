## 方法与范围

在同一套对象、同一组 PVC 上先运行标准探针基线，再开启 sidecar。基线每架构六次 Pod 重建；
优化组每架构单节点运行时停启、九次 Pod 重建、一次同 Pod 内 MinIO SIGKILL、整组缩容至 0 后恢复。
每次校验都先清空本地回读目录，再全量下载并核对独立保存的 SHA256，不手工 heal、不重写数据掩盖错误。

初始 103 个对象包含 100 个小对象、空对象、1 MiB 和 80 MiB 随机对象。
单节点离线时再写入 8 MiB 对象和一个小对象，总计 105 个。小对象成功上传后才加入连续读集合，
因此连续读中不存在“先读尚未上传对象”导致的正常 404。

持续读取分两路：原始签名 GET 不重试；另一条明确调用已知对象适配器，最多五次、校验预先持有的内容哈希。
原始请求、适配器的每次 HTTP 结果和最终退出码分别保存。完整停机时不要求服务可用，停机前后验证持久化。

环境：x86 使用三台新申请的独立内核池化 VM；ARM 使用用户提供的 ARM 主机上三个独立
Kubernetes 节点容器。K3s v1.35.10+k3s1，三服务器、每服务器一盘、同架构原生运行。
x86 VM 间使用测试专用 SSH 隧道；ARM 使用独立 Docker daemon 和 overlayfs。
两组应用相同的测试 CoreDNS 短 `.svc` 搜索规则以消除该隔离环境的解析延迟。
ARM 三节点共用物理主机，x86 VM 的物理宿主机隔离也未经认证；本轮不作为物理主机故障验收。

镜像归档及源码包来自上述 CI；Helm 候选和可重放脚本在后续提交中加入仓库，
并不包含在该次构建生成的旧源码归档内。见 [Helm 候选](deployment/chart/README.md) 和
[分布式测试脚本](deployment/tests/distributed/README.md)。

**验收未全部通过，不发版。** 标准探针兼容问题已通过 Helm 解决；错误 404 仅得到缓解，
当前上层就绪检查不能可靠替代 MinIO 内部的重加入修复。两种架构都没有观察到持久数据丢失或内容损坏。

`000` 是采集脚本对 curl 传输错误/超时的记录，不是服务端 HTTP 状态码。
两组测试时长、重建次数及请求总量不同，不应把这些计数解释为可直接比较的故障概率。

ARM 的九次错误 404 位于 **2026-11-19 17:21:43–17:21:44（Asia/Shanghai）**。
Kubernetes 事件显示该时段正在停止第三轮的 `qa-minio-1`，前一个 `qa-minio-0` 已恢复并通过全量对象校验。
其中包括先前单节点离线时写入的 `outage-small`，是已存在对象的错误“缺失”响应。
这发生在滚动重建窗口，**不是之后同 Pod 内单独重启 MinIO 的测试**。
本轮没有逐请求后端跟踪，不能仅据时间戳断定由哪个 Pod 或内部调用返回。

ARM 适配器看到的一次 404 重试后成功；一次 exit75 对应连续五次连接失败，正确报告临时不可用。
额外负向用例两边均通过：真正不存在的对象仍为 404/NoSuchKey，错误凭据 403 不重试，
内容哈希不符立即拒绝且不生成目标文件，五次耗尽返回 exit75 而不伪造成功。
这不意味着所有 S3 请求或数据库读取链路已接入适配器。

持久化与恢复检查两边均通过：

- 原始 103 个对象的 SHA256 全部保留；离线新增两个对象后最终 105 个对象全量一致。
- 节点离线时为 2 盘在线、1 盘离线，能够读写；恢复后为 3 盘在线、0 盘离线。
- 各九次 Pod 重建后全量校验一致；恢复时间 x86 30–49 秒、ARM 33–50 秒。
- 同 Pod 内 MinIO SIGKILL 后 Pod UID 不变、MinIO 重启次数增加、检查组件重启次数不变；
  日志记录两个不同进程标识分别重新准入，恢复后全量对象一致。
- 全部缩容至 0 后恢复，3 个原始 PVC UID 和卷名不变；每盘 `distributed` 桶下各 105 个 `xl.meta`。

## 使用边界与后续定位

本候选只验证三服务器、每服务器一盘、HTTP 和业务 Service 路径。未证明直连 Pod、其他拓扑、
高并发写入、版本对象、删除标记或更复杂网络故障下的行为。短暂连接失败仍存在，不能承诺零中断。

就绪探针可以控制业务入口，不能阻止 MinIO 节点间 RPC，也不能证明所有对象的元数据状态已经一致。
继续采用无补丁路线，需要进一步捕获请求后端和节点内部状态，再决定退出排流、部署协调或客户端处理是否足够。
不能只延长等待时间，或对任意 404 无差别重试后，就宣称根因已修复。
